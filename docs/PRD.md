# PRD: Todo (claude_basic_app)

## 목표
외부 서비스 의존 없이 로컬에서만 동작하는 가벼운 할일 관리 데스크톱 도구. 켜자마자 1초 안에 새 할일을 적을 수 있다.

## 사용자
Windows 데스크톱에서 작업하는 개인 사용자(개발자/지식 노동자). 동기화·협업·계정 없이 자기 PC 한 대에서만 사용한다.

## 플랫폼
- 1차 타겟: **Windows 10/11 (x64)** 데스크톱
- 배포 방식: MVP는 `flutter build windows --release` 산출물(단일 exe + 동봉 DLL/asset 폴더). MSIX 패키징은 후속 작업.

## 핵심 기능
1. **할일 등록** — 리스트 상단 인라인 입력바에 제목을 적고 Enter 또는 [추가] 버튼으로 즉시 등록. 메모/마감일은 선택 입력.
2. **할일 수정** — 항목 클릭 시 다이얼로그(FDialog)에서 제목·메모·마감일을 편집하고 저장.
3. **할일 삭제** — 수정 다이얼로그 내 [삭제] 버튼으로 즉시 제거.
4. **완료 토글 + 필터** — 각 항목의 체크박스로 완료/미완료 전환. 상단 탭으로 **전체 / 미완료 / 완료** 보기 전환.

## MVP 제외 사항
- macOS / Linux 데스크톱 빌드
- 모바일(iOS / Android) 빌드
- 클라우드 동기화 / 다기기 동기화
- 알림 / 리마인더 (마감일 도달 시 시스템 알림)
- 검색, 태그·카테고리·우선순위
- 자동 업데이트
- 로그인 / 계정

## 비기능 요구사항
- **콜드 스타트 시간**: release 빌드 기준 2초 이내
- **오프라인 동작**: 완전 오프라인 (네트워크 호출 0건)
- **데이터 저장 위치**: `%APPDATA%\com.example\claude_basic_app\todos.db` (sembast 단일 파일)
- **최소 사양**: Windows 10 1809+, RAM 4GB
- **데이터 영속성**: 앱 재시작 후 데이터 유지. 비정상 종료 시에도 sembast 트랜잭션 단위까지 보존.

## 디자인
- **톤**: forui(zinc 팔레트) 기반 미니멀 데스크톱 도구. shadcn/ui 톤의 정보 밀도 높은 레이아웃.
- **차림 모드**: 시스템 라이트/다크 모드 자동 추적 (`MediaQuery.platformBrightnessOf`).
- **색상 방향**: 무채색(zinc) + 포인트 1가지 (forui 기본 primary). 색상 하드코딩 금지, FTheme 토큰만 사용.
- **레이아웃**: 좌측 정렬, 최대 너비 1024px, 4의 배수 간격 단위.
- **AI 슬롭 금지**: blur(글래스모피즘), 글로우 애니메이션, 그라데이션 텍스트, 보라/인디고 브랜드 컬러, 모든 모서리 24px 둥글림 — `docs/UI_GUIDE.md` 안티패턴 표 준수.
